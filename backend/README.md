# Hoyo Analyzer: backend

Laravel 13 API, importers, build scrapers and the analyzer. See the [project README](../README.md) for setup,
commands and how everything fits together.

```bash
php artisan serve                 # API on http://127.0.0.1:8000
php artisan builds:sync --help    # scrape builds
php artisan accounts:import --help
php artisan test
```
