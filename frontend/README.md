# Hoyo Analyzer: frontend

Angular 21 + Angular Material app. See the [project README](../README.md) for setup.

```bash
npx ng serve               # http://localhost:4200 (proxies /api to http://127.0.0.1:8000)
npx ng test --watch=false  # unit tests (Vitest)
npm run build:backend      # production build into ../backend/public/app
```
